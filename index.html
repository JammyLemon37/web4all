An Introduction to Web Development

The 3 Layer Model

The 3 Layer Model is a useful structure, separating content, presentation and behaviour, that webpages can follow to ensure a good end-user experience. That's all a bit of a mouthful though so, just for a minute, let's think of a website like a stack of 3 pancakes that all each make each other better. 3 pancakes are a lot more impressive and interesting than just 1 sad lonely pancake!

The first pancake (or layer) is the Content layer. This provides the basic structure and base content for our website (eg. text, images and video). The content layer is controlled by HTML.
The second pancake (or layer) is the Presentation layer. CSS controls the presentation layer and adds styling, layout and other aesthetically pleasing properties to the already existing HTML content. CSS can be applied at the top of a HTML file, inline within an opening HTML tag itself or as an externally linked stylesheet.
The third pancake (or layer) is the Behaviour layer. This provides interactivity to our website and is implemented using a language called JavaScript. This allows users to interact with a website by way of buttons and keyprompts etc.

The 3 Languages of Web Development

HTML

The Content Layer

HTML stands for HyperText Markup Language. It's the standard markup language that's used to structure the content of a website. The language was invented by Sir Tim Berners-Lee (the creator of the World Wide Web!) between 1989 and 1991 while working at CERN in Switzerland.

HTML controls the content layer of a webpage via the use of tags (think of labels!). When content is put between a HTML opening tag and a closing one, this can now be referred to as a complete HTML element. Most (but not all) HTML elements have an opening and a closing tag.

Use of effective and descriptive HTML tags add semantic meaning. When we refer to HTML code as having "semantic meaning", we mean that the HTML tags in use provide a description of the HTML content within themselves for browsers, other programmers and screen reading technology. HTML files are saved with the file suffix ".html".

NB. HTML files are also commonly referred to as documents.

Below are some common HTML tags:

  • html - The root element of an HTML file
  • head - Contains metadata (data describing data) about the HTML file it is within
  • body - Contains the content of a webpage displayed to the end-user
  • div - A division tag. A non semantic and generic block level element
  • p - A paragraph tag. Tends to contain text content
  • a - An anchor tag. This is used to denote and style an interactive link
  • section - Similar to a div tag but carries more semantic meaning and tends to group related content together
  • ul & ol - Unordered List, Ordered List
  • li - A list item within an ol or ul element
  • input - Used to implement interactive input of varying types (buttons, text forms etc.)
  • span - Used to apply unique styling to a smaller inline portion of (usually) text

CSS

The Presentation Layer

CSS stands for Cascading Style Sheets. It is a stylesheet language and it's purpose in life is to describe how the content of a HTML file should look aesthetically. CSS targets HTML via the use of selectors. Selectors are syntax patterns that can be written to target HTML elements to apply styling to them. There are many different ways to target selectors that you can read further about on our CSS Selectors page.

Styling is applied to these selectors via declarations stipulating properties and their values.

The syntax is as follows: Property: Value;Eg. color: blue; "color" is the property and "blue" is the value assigned to it. Together these form to make a declaration.

Multiple declarations to style one selector within two curly braces is referred to as a declaration block. A declaration block with a selector associated with it at the top is called a ruleset. CSS Rulesets can be written in a variety of places.

CSS can be placed, internally, at the top of the HTML file they apply to within a style element within the head element. Alternatively CSS can be written inline within the exact tag they are to be applied. CSS can also be written an external file, called a CSS stylesheet, that is linked at the top of the page within a link tag within the head element.

Applying CSS styles internally and inline generally results in more messy and less readable files, therefore it is a good rule of thumb to try prioritise using external CSS if possible! Feel free to learn more about this on our Separating HTML & CSS Content page.

CSS uses a style hierarchy to apply styles in the manner. The CSS Style Hierarchy consists of 3 principles those being specificity, inheritance and the cascade which all come into play in different ways in order to determine which styles are applied where, when and in which order or precedence. CSS files are saved with the ".css" file suffix.

JavaScript

The Behaviour Layer

JavaScript (JS) is a high-level programming language that is used to to make webpages dynamic and interactive. It is commonly accepted that JavaScript is a "Turing Complete" programming language.

A Turing complete language is able to simulate the Turing machine (built by Alan Turing) and can perform any Turing computable function.

Turing computable functions include conditional branching (if, else, else if statements), iteration and recursion (loops evaluated against a Boolean expression) and the ability to read, modify and store data while a program runs.

Within web development, JavaScript can be used to modify the Document Object Model (DOM). The DOM is the representation of a HTML file structured in the form of a tree. It's a programmatic logical tree structure that clearly and exactly sets out which elements are children, parents and siblings of each other. Through JavaScript amending the DOM, interactivity can be added in real time to the website. This can be in the form of the website responding to button clicks, keyboard prompts and updating its own webpage content in real time without requiring a full page refresh.

JavaScript is used much further afield than simply front-end webpage development. Node.js is a JavaScript runtime that, when used, allows JavaScript code to be run outside the browser. Apart from controlling the behaviour layer of webpage JavaScript can be used for server-side scripting and can also be used to develop a variety of web-based applications and games. JavaScript files are saved with the ".js" file suffix.
