Separating HTML & CSS Content

The Purposes Of Separating HTML & CSS Content

CSS declarations can be applied to a HTML document in 3 different ways. CSS can be included inline, internally, or externally. Generally it is a good rule of thumb to add CSS styling externally wherever possible. This increases the readability of your files. It also allows multiple HTML documents to take advantage of one single set of CSS declarations. This ensures an efficient workflow and increases code maintainability and readability. Below we'll delve deeper into the various ways CSS styling can be applied to HTML along with some examples.

Inline CSS

CSS can be applied to HTML via writing the "property: value;" declarations "inline". This means to write all the declarations directly within the opening (or self-closing) tag of the HTML element that you want to apply the styling to. This can be helpful for small changes or overrides in places when using a generalised class selector. This is because inline styling has a higher specificity than a class selector and therefore will work in the case of changing a rule that you want to override just in 1 or 2 places.

However, generally it's advisable to avoid overly relying on applying CSS via the inline method if possible. Firstly this is because, oftentimes you may end up having to re-type various declarations multiple times. In this case it would be easier to declare a class ruleset that can be reused multiple times. Secondly, inline CSS can greatly increase the amount of text in a small area within a file. This can serve to make code more messy, less readable and more difficult to maintain and potentially debug. Internal CSS

CSS styling can be applied to HTML "internally". The term "internally" refers to the fact that the CSS declarations are all written within the very HTML file that they are intended to apply to. Writing CSS declarations for each HTML file can become quite longwinded and inefficient though. Entire websites are made up of many individual HTML files. Applying CSS styling internally may result in you having to re-type the same or very similar declarations over and over just so that they can be used within more than one HTML document.

Furthermore, while internal CSS is neater than writing CSS inline within HTML tags, adding many CSS declarations internally will result in some very long HTML files which can become somewhat hard to read and confusing. External CSS

CSS styling can be applied to HTML "externally". This is done by writing all of the CSS selectors and their relevant declaration blocks in a .css file that is outside of the HTML file it is to be applied to. To then make the contents of the .css file accessible within the HTML file, you add it via a link tag within the "head" element.

The "rel" attribute stands for relationship and is set to "stylesheet" indicating the link you are adding into the file is in fact a stylesheet. The "type" attribute stipulates the type of content being linked. The value of the "type" attribute must be a valid MIME type, in our case "text/css". This stipulates the link is to a file of text which is of the css type. The "href" attribute stands for hypertext reference. The value of the "href" attribute is the URL (Uniform Resource Locator) of the CSS file that you want to add. Oftentimes this will be prefixed with "./" indicating that the URL you are providing is at the end of a relative path not an absolute path.

Some Relevant Definitions:

  • MIME - These used to be known as Multipurpose Internet Mail Extension Types but are now known simply as Media Types. They indicate the nature and format of a document or file. Most commonly written in the form "type/subtype".
  • Relative path - A path to a file that begins from the current file you are referencing the link from.
  • Absolute path - A path to a file that begins from the root of a filesystem directory.
  • URL - A Uniform Resource Locator is the address of a unique resource either on the internet or locally (on your computer)

Applying CSS externally is generally the most recommended way to apply CSS styling to a HTML file. This is because separating the content and the formatting keeps files neater and more organised. This increased the readability of the code being written. This makes it easier to maintain and debug especially across larger codebases that may have more than one engineer/developer working within them. Furthermore external CSS can easily be linked across many different HTML files which allows multiple files access to use and reuse class rulesets to ensure uniform, professional styling across the webpage. External CSS

CSS Code
/* filename: style.css */

p
{
    color: red;
    font-weight: bold;
}

HTML Code

<head>
    <link rel="stylesheet" 
    type="text/css" 
    href="./style.css"/>
</head>

<body>
    <p> 
        This is some red, 
        bold text. 
        The CSS has been 
        written externally
        and added via a link 
        tag in the head 
    </p>
</body>
