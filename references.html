References & Learning Materials

Below are short descriptions and links directing you to the resources I used to learn the fundamental principles and improve my skills in HTML & CSS so that I could build this website.

Codecademy

Codecademy is an online learning platform that provides courses of varying lengths on a variety of topics across Computer Science/Software Engineering. I took advantage of a variety of their HTML & CSS courses in order to learn more about the languages and practice my skills through practice exercises/projects.

CS50

CS50 is Harvard University's collection of free online open-source Computer Science courses. It is described as an "introduction to the intellectual enterprises of computer science and the art of programming". There are a variety of really helpful lectures, short-form content, notes and problem set exercises to help you learn about a variety of Computer Science topics. In particular I found the CS50X Week 8 "HTML,CSS,Javascript" lecture really helpful before building this website.

W3Schools

W3Schools is a website that has reference pages, tutorials, practice exercises and explanations for a variety of programming languages and technologies available free of charge. In particular I found the HTML & CSS tutorials really helpful. I also made use of their reference pages and explanations in order to help me learn and research further about topics such as CSS selectors and specificity.

GeeksforGeeks

GeeksforGeeks is a website (quite similar to W3Schools in a way) that provides articles, examples and tutorials on a variety of Computer Science topics and programming languages. I found some of their explanations about certain topics to be helpful when learning and researching about HTML & CSS.

MDN

MDN Web Docs (formerly called Mozilla Developer Network) is a website that contains a variety of references, technical explanations and examples related to web development. MDN is the closest thing that HTML, CSS and JavaScript has to a comprehensive "manual pages" document. While MDN features explanations that are quite technical and comprehensive they are still quite accessible, clear and learnable for those interested in delving deeper into HTML, CSS and other web development technologies too.
